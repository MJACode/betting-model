**Session summary (2026-10-09 — a failed Anytime TD touch read no longer opens the board; a typed line commits once on Android):**

Follow-up on draft #899. Two review items, plus the wide-list flash and a
report on pocket quarterbacks. The stepper wrap is unchanged.

A failed touch read used to resolve to undefined. Season and H2H Anytime TD
then treated `touched` as unknown and kept anyone with games, and the next
load had nothing to retry against except that missing set. `touchSetAfterFailure`
keeps the set it is handed: a last good set for the same key stays, and a set
for another key is not cleared. The failed key is recorded, and
`shouldFetchTouchSet` asks again on the next load and on pull-to-refresh. With
no set for this key, `touchBoardView` is `error` and the list is `EMPTY_ROWS`
with one line: "Couldn’t load who has touched the ball. {cause} Pull down to
retry." The cause is the existing `friendlyCause` sentence. The same view is
`loading` until the read for this key resolves, so the unfiltered rows are not
painted while the set is in flight. A retry that already has a set leaves the
filtered list up. `verify_stats_board.ts` covers a failure with a last good
set, a failure with none, a stale failure, and the skeleton hold.

Android already had `returnKeyType="done"` and `onSubmitEditing`. Done then
fires blur, and both called the same commit with the same draft.
`commitTypedLineOnce` latches on the first call; the second applies nothing.
Focus clears the latch. `verify_player_log.ts` commits "50" from 51 once, then
asserts the second call changes nothing.

Not done: the touch filter is unchanged. Of 51 QBs in `nfl_player_game_log`
season 2026, 2 have carries, receptions and targets all zero — Andy Dalton
(PHI, `NFL_2026_03_PHI_CHI`, 2026-09-28: 0-for-1, 0.0 yards, 0 rushing /
receiving / passing TDs) and Shedeur Sanders (CLE, `NFL_2026_03_CAR_CLE`,
2026-09-27: 1-for-1, 0.0 yards, 0 TDs of any kind). `player_prop_odds` has no
row for either name on any market with `game_date >= 2026-09-01`. Both have
older `player_anytime_td` rows (Dalton through 2025-10-26, Sanders through
2026-01-04). On this season's log they are not rushing or receiving TD
candidates. Reported, not changed.
